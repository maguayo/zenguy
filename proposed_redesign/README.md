# Overview redesign proposals

Standalone HTML mockups for the `apps/frontend` overview. The app was not changed.

Open `index.html`, or open `1.html` … `20.html` directly.

**1.html is the original Paper & Pulse proposal** (kept). 2–20 were rewritten as SaaS product layouts in the same visual family: cream / ink / violet, Geist, app sidebar.

Same snapshot in every file: Aguayo Staging, Checkout at 0,00 €, Checkout API 502, Add to cart running, 184/300 runs.
